# WZQ — Creative Portfolio

A dark, editorial portfolio for a Visual / AI / Brand Designer, built with React + Vite.

## Quick start

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Customize

- Edit the projects, skills and contact details in `src/App.jsx`.
- Adjust typography, colors and layout in `src/styles.css`.
- Replace the remote placeholder photography with your own images and hero video. The hero currently uses an animated CSS treatment, so it works without a video file.
- Replace the placeholder email before publishing.

## Sections

Full-screen Hero · About · Selected Work · Expertise · Contact

Designed desktop-first for a maximum 1700px content width, with responsive tablet and mobile layouts.
